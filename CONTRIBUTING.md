# Contributing to Danksy DroidOps

Open an issue for a reproducible bug or proposed change. Include the affected version and relevant steps without private screen content. For a code change, keep the scope focused, add a behavioural test when appropriate, and run the checks in the maintainer guide.

The visual layout, per-user settings migration, controller stop behaviour and alert deduplication need particular care. Changes to these areas should describe their effect and how they were checked. Contributions are accepted under the repository's MIT licence.

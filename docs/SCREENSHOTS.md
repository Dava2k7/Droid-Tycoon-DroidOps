# DroidOps screenshots

The README includes two captures of the current application:

- `images/droidops.png`: the main window at its fixed 1080 × 780 size.
- `images/droid-watch.png`: the notification filters and watcher controls.

These are captures of the actual Qt widgets rendered on Linux, rather than design mock-ups. The main window is disconnected and no game, virtual controller or watcher was started. Windows fonts and native dialog frames may look slightly different.

Keep both files at these paths when uploading the repository so the README can display them. No private game screenshots or account information are included.
